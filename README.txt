BAVADHARANI'S PERSONAL PORTFOLIO
================================

FILES
- index.html : main portfolio page and sections
- style.css : visual design, responsive layout, and animations
- script.js : mobile navigation, scroll reveals, interactive orb, and intro animation
- personal-details.html : personal profile and education details
- introduction.html : Let's Hear page with voice recording controls
- audio/bavadharani-introduction.mpeg : original voice recording used on the Let's Hear page
- certificates.html : certificate gallery page linked from Education
- bavadharani-photo.jpeg : profile photo used in the portfolio

HOW TO VIEW
1. Extract the ZIP file.
2. Open the portfolio folder in VS Code.
3. Open index.html using Live Server (recommended), or open it in a browser.
4. On the main page, select About > Details.
5. On the Personal Details page, select “Listen to my introduction” under “Let's Hear”.
6. Press “Play Introduction” to listen. Use “Pause” or “Restart” as needed.
7. Keep the audio folder beside the HTML files; the audio player depends on it.

Internet is only needed for the optional Google Fonts. The rest of the site and the included recording work locally.

IMPORTANT CUSTOMISATIONS BEFORE SUBMITTING
1. Confirm the email, GitHub, and LinkedIn links in index.html before publishing.
2. Replace each project card's GitHub profile link with the exact repository URL once that project repository is public.
3. Verify both live demo URLs and all project details before publishing.
4. Verify every certificate, internship, achievement, and skill description before publishing.
5. Certificate PDFs are stored in the certificates folder and linked from certificates.html. Only uploaded certificate files are listed on the Courses & Certificates page.
6. Include only certificates and achievements you have actually received.

PUBLISHING
- GitHub Pages: upload the files to a GitHub repository and enable Pages in repository Settings.
- Vercel: import the repository and deploy as a static site.

DESIGN NOTES
Custom dark interface with mint/violet accents, CSS-generated 3D-style orb and orbit animations, responsive navigation, interactive pointer movement, animated satellite photo introduction, and floating background bubbles.

- Use Live Server in VS Code and keep project-details.html beside index.html and style.css.
